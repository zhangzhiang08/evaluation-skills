# 按管辖行拆分履职评价表

把一份履职评价汇总工作簿拆成 18 份 Excel，每个管辖行一份。适用于综服经理、运营内控经理两支队伍的第一次基础数据拆表和第二次征求意见稿拆表。使用时附上当期原表，告诉 Agent 队伍和轮次即可。

## 第一次使用

1. 安装整个 `branch-evaluation` 文件夹。安装后的目录里应能同时看到 `SKILL.md` 和 `scripts/workflow.py`。在原开发项目中，也可以直接使用项目里的 Skill。
2. 在能够读取附件、运行 Python 和保存文件的 Agent 中新开任务。分发包使用 Python 3.11，依赖列在 `scripts/requirements.txt`。两轮拆表使用的管辖行名单已随包提供。
3. 附上当期汇总表（`.xlsx`），发送一句话，例如：

> 使用 branch-evaluation，把附件按运营内控经理第二次拆表规则拆分。完成后给我结果目录，列出没有找到归属字段的工作表。

## 模式速查

| 你要处理的表 | 对应规则 |
| --- | --- |
| 综服经理 · 第一次基础数据表 | 名称含“说明”“校验”“评价方案”“名额分配”的工作表完整保留，其余表按归属字段处理。 |
| 综服经理 · 第二次征求意见稿 | 沿用上述保留范围；清理拆分数据区中的整行空白，有内容的说明行可能保留。 |
| 运营内控经理 · 第一次基础数据表 | 隐藏工作表、评价方案和名额分配表完整保留；可见校验表参与拆分。 |
| 运营内控经理 · 第二次征求意见稿 | 沿用上述保留范围；可见校验表参与拆分，并清理拆分数据区中的整行空白。 |

运营内控的隐藏工作表保留原显隐状态及整表数据。综服经理按表名和字段处理隐藏工作表。两支队伍均可能将缺少拆分字段的工作表整张复制到各支行文件；发给支行前值得先看报告里的这份表名清单。

## 去哪里看结果

每次运行会在输出位置新建一个批次目录，里面有支行工作簿和 `拆分运行报告.json`。例如源文件名包含“2026年三季度”，运营内控第二次拆表的宝安文件名为 `附件1：【征求意见稿】2026年三季度运营内控队伍履职评价计分表（宝安）.xlsx`。源文件名没有可识别的季度时，使用源文件名加支行简称。

只想看某张表为何为空，可以继续问：

> 请核对本批次宝安文件里的“6.1加分项（一、价值贡献）”。源表里有几条可归到宝安的明细？拆完保留了几条？请说明判断归属用的字段。

需要网页时，在拆表请求末尾加上“同时生成 HTML”。已有批次也可以单独要求“为这个批次刷新 HTML”。网页从可见工作表和可见行列取数，缺少计算结果的公式会标为“待重算”。

## 以后怎么改

更改 Agent 怎样接收任务、怎样汇报，编辑 [SKILL.md](SKILL.md)。调整抽查方式或解释报告字段，编辑[验收说明](references/验收说明.md)。调整哪一行归哪个支行、哪些表保留，则在原项目修改对应的 Python 拆表规则，运行 `package_skill.py` 重新打包。
